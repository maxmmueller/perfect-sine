# Logo studies

Open `index.html` directly or visit `/design/logo-studies/index.html` on the local
Vite server. Compare light and dark backgrounds, toggle small previews, and select
a favourite. Selection is local to the preview and does not change the game.

Each direction includes transparent light and dark SVG assets. Kalam lettering
is outlined, so the assets do not need installed fonts or external requests.
The font license is available in `../../public/fonts/OFL.txt`.
